# 🧹 Clean Data

This folder contains the cleaned and transformed datasets used for the CareScope project.

The raw datasets were processed to improve data quality, consistency, and usability for SQL analysis and dashboard development.

### Cleaning & Transformation

- Removed unnecessary columns
- Handled missing and inconsistent values
- Standardized column names
- Corrected data types
- Removed duplicate records where required
- Standardized categorical values
- Prepared datasets for database loading and analysis

The cleaned datasets serve as the input for the SQL analysis stage.
