# 🗄️ SQL Analysis

This folder contains the SQL analysis performed for the CareScope project.

MySQL was used to analyze hospital patients, encounters, procedures, claims, and financial information.

### Analysis Areas

- Patient and encounter analysis
- Encounter class analysis
- Procedure analysis
- Claims cost analysis
- Payer coverage analysis
- Healthcare service analysis
- Financial performance analysis
- Time-based trends
- Aggregated healthcare metrics

### SQL Techniques

- SELECT and filtering
- GROUP BY and aggregations
- JOINs
- CASE statements
- Subqueries
- CTEs
- Window functions
- Date-based analysis

The results generated from SQL analysis were used to support the dashboard and reporting stages.
