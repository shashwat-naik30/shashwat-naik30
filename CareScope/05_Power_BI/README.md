# 📊 Power BI Dashboard

This folder contains the Power BI dashboard developed for the CareScope project.

The dashboard provides an interactive overview of hospital patients, healthcare services, encounters, procedures, and financial performance.

### Dashboard Highlights

- 👥 Total Patients
- 💰 Total Claims Cost
- 🏥 Total Procedures
- 💳 Total Payer Coverage
- 📋 Total Encounters
- 📊 Encounters by Encounter Class
- 💵 Claims Cost by Encounter Class
- 📈 Total Encounters Trend
- 📈 Total Claims Cost Trend

### Purpose

The dashboard transforms the analyzed healthcare data into an interactive visual interface for understanding operational and financial patterns in the healthcare system.

Power BI was used for data modeling, calculations, visualization, and interactive analysis.
