# 📊 Dashboard Table

This folder contains the dashboard-ready tables created from the cleaned and analyzed healthcare data.

The tables were prepared to support efficient visualization and reporting of hospital patient, service, encounter, and financial metrics.

### Dashboard Data Includes

- Patient metrics
- Encounter metrics
- Procedure metrics
- Claims cost
- Payer coverage
- Encounter classifications
- Time-based healthcare trends

These prepared tables provide the analytical foundation for the Power BI dashboard.
