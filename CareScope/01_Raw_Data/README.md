# 📦 Raw Data

This folder contains the original datasets collected for the CareScope project.

The raw data is preserved in its original form and serves as the starting point for the data cleaning, transformation, and analysis process.

The datasets contain information related to:

- 👥 Patients
- 🏥 Healthcare encounters
- 🩺 Procedures
- 💰 Claims and costs
- 💳 Payer coverage
- 📅 Healthcare service dates

No analytical transformations are applied to the original datasets in this folder.
