# Airbnb Market & Performance Analysis

## 📊 Project Overview

This project is a Power BI-based analysis of Airbnb listing performance, ratings, reviews, and market trends. The dashboard transforms Airbnb data into interactive visual insights to understand listing activity, city-level market share, ratings, review patterns, trust, and seasonality.

## 🎯 Objectives

- Analyze Airbnb listing activity and new listing trends.
- Compare market share across different cities.
- Analyze ratings and understand listing performance.
- Examine review frequency and seasonal patterns.
- Identify trends and insights through interactive Power BI dashboards.

## 🛠️ Technology Stack

- Power BI
- DAX
- Data Visualization

## 📈 Dashboard Sections

### 1. Overview
Provides a high-level view of Airbnb listing activity and new listing trends.

### 2. Ratings
Analyzes ratings, city-level market share, and listing performance.

### 3. Reviews
Examines review frequency, trust-related indicators, and seasonal review patterns.

## 🔍 Key Analysis

- New listing trends
- Market share by city
- Ratings analysis
- Review frequency
- Trust analysis
- Seasonal patterns

## 📌 Project Outcome

The project converts Airbnb data into an interactive Power BI dashboard that helps explore market trends, listing performance, ratings, and customer review behavior through clear and intuitive visualizations.
