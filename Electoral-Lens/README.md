## 🔎 Project Overview

Electoral Lens analyzes the Indian General Election 2024 to uncover insights into:

- 🗳️ Election and seat distribution
- 🤝 Alliance-wise performance
- 🏛️ Party-wise performance
- 🗺️ State and regional analysis
- 🏆 Winner analysis
- 👥 Candidate and gender analysis
- ⚔️ Closest victories
- 🧑‍💼 Independent candidate analysis
- 📈 Election-level insights
